SET UP INSTRUCTIONS:

- It is recommended to use a virtual environment, but if not the next step still applies.

- To help set up the environment, I've included a requirements.txt file in this repo. To get all the necessary dependencies, run:
    pip install -r requirements.txt 


RUNNING INSTRUCTIONS:
- To run the code, just run the following command in the terminal:
    python mountain_car_environment.py

- It should spit out 3 plots, one for the learning curve, one for the Q values, and one for the greedy policy. It will also save a video to the /videos directory.


- All of the experiments I ran are organized into their own directories in the root, as well as inside the videos folder.
